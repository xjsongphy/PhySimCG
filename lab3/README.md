# Lab 3: FEM Soft Body Simulation

## Run

From repository root:

```bash
uv run lab3 --demo basic
uv run lab3 --demo b1
uv run lab3 --demo b2
uv run lab3 --demo b3
```

Equivalent command:

```bash
uv run python -m lab3 --demo basic
uv run python -m lab3 --demo b1
uv run python -m lab3 --demo b2
uv run python -m lab3 --demo b3
```
